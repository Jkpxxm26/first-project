# first-project

โปรเจ็คนี้เป็นโปรเจ็คชิ้นแรกที่ผมอยากลองทำเมื่อผมเรียนและศึกษาวิธีการสร้างโครงสร้างเว็บพื้นฐาน ผมเลยลองเอาความรู้ที่ผมมีทั้งหมดมาลองประยุกต์การสร้างเว็บ ถึงหน้าตาอาจจะไม่สวยมากแต่ผมก็รู้สึกภูมิใจเพราะเป็นสิ่งที่ผมลองผิดลองถูกไปกับมันโดยไม่ใช้ตัวช่วยเลย โปรเจ็คแรกนี้ผมยอมรับเลยว่าผิดพลาดเยอะมาก ทั้งเรื่องการวางโครงสร้างหน้าเว็บหรือแม้กระทั่งโครงสร้างของโค๊ด เพราะผมต้องการให้โค๊ดของผมอ่านง่าย แต่ช่วงแรกๆผมยังไม่ค่อยเก่งเรื่องการคิดเชิงLogic ว่าเขียนโค๊ดแบบนี้จะไปกระทบกับอะไรบ้าง เว็บนี้จริงเปรียบเสมือนเว็บไซต์เวอร์ชั่นแรกในชีวิตของผมเลยครับ
